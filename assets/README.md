# Photo assets

Place the four Rajshahi photos in this folder with these exact filenames:

- `IMG_20260620_075746_665.jpg` — Evidence #001 / Ratul solo (the funny one)
- `IMG-20260620-WA0021.jpg` — Evidence #002 / group selfie
- `IMG-20260620-WA0043.jpg` — Evidence #003 / hallway photo
- `IMG-20260620-WA0027.jpg` — Evidence #004 / outdoor group photo

The site is already wired to these filenames. The GitHub connector used for this build can write UTF-8 text files but cannot upload binary image bytes, so these four image files are the only remaining deployment step. Do not rename them unless you also update `index.html`.
