# RATUL.EXE

An interactive birthday experience for Ratul — Birthday Protocol // 10.09.2026.

## Experience flow

Classified boot → subject file → Ratul Science™ → Lankala detection → annual treat investigation → future path simulator → Rajshahi memory archive → friendship reveal → birthday message → real-world gift troll → finale.

## Files

- `index.html` — page structure and story scenes
- `style.css` — responsive cinematic UI and animations
- `script.js` — navigation, audio cues, progress, future simulator and confetti
- `assets/` — four Rajshahi photos used by the archive
- `.github/workflows/pages.yml` — GitHub Pages deployment workflow
- `.nojekyll` — static-site marker

## Test locally

The simplest test is to download/clone the repository and open `index.html` in a modern browser. For the most accurate local test, run a tiny static server from the repository folder:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000/`.

## Deploy with GitHub Pages

1. Open the repository **Settings**.
2. Open **Pages** under **Code and automation**.
3. Under **Build and deployment → Source**, choose **GitHub Actions**.
4. Pushes to `main` will then trigger the included Pages workflow.
5. After the workflow succeeds, the site will be available at:
   `https://samaun-99.github.io/RATUL.EXE/`

If GitHub shows the workflow waiting for Pages to be enabled, complete step 3 once and rerun the workflow if necessary.
